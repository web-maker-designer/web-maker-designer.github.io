Who I Am

I'm a self-taught web designer and developer who lives at the intersection of clean visuals and technical curiosity. Every project I touch is built with intention — no templates, no shortcuts.

Beyond the front end, I operate in the world of software exploitation — building custom executors and hacks for apps and games. It's the same obsessive attention to how systems work, just from the other side of the screen.

Whether it's pixel-perfect UI or reverse-engineered logic, I approach everything with a builder's mindset.

The Journey

// 2020 — THE BEGINNING
First Lines of Code
Started tinkering with HTML and CSS out of pure curiosity. Built my first webpage — a messy, lovable experiment that sparked everything.
// 2021 — GOING DEEPER
Learning Design Systems
Moved beyond static pages into JavaScript, responsive design, and UI/UX principles. Started understanding how the web is actually experienced.
// 2022 — THE OTHER SIDE
Exploring Software Internals
Got fascinated with how apps and games work under the hood. Started writing scripts, exploring memory, and building my first executors and tools.
// 2023 — LEVELLING UP
Real Clients, Real Projects
Started taking on web design commissions. Built websites for others while simultaneously developing a reputation in the executor/hack community.
// NOW — ONGOING
Building & Breaking_
Continuously pushing both crafts forward. Designing sharper, building faster, and engineering tools that do what others say can't be done.
